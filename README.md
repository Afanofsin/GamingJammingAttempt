# GamingJammingAttempt
---

## Overview
This repository contains project created for Shovel Game Jam 2025. As a team we were able to get 12th place overall from more than a 1000 entries.
The link to project on itch.io platform: https://dmeansdream.itch.io/gamedev-kick-off-fixed

---

## Team Responsibilities
DmeansDream/Afanofsin - Integration of a modular card and battle system that closely adheres to Open/Closed principle and relies on abstractions and extensibility. Creation of general game architecture that ties all of it's systems into a coherent structure.
albinolama - Creation of a dialogue and house exploration systems as well as UI integration.
INwirstD - Design and art assets creation.
